# EasyTrader24

Plataforma web desarrollada para la gestión y seguimiento de operaciones de trading, administración de ciclos financieros, reinversiones y control de usuarios.

## Funcionalidades principales

- Gestión de usuarios y roles.
- Administración de ciclos de trading.
- Control de inversiones y reinversiones.
- Seguimiento de operaciones financieras.
- Automatización de cálculos y procesos.
- Gestión de cierres y periodos.
- Historial y trazabilidad de operaciones.
- Panel administrativo.
- Autenticación y control de acceso.
- Gestión de información en tiempo real.

## Tecnologías utilizadas

- React
- TypeScript
- Firebase
- Firestore
- Firebase Authentication
- Firebase App Hosting
- Vite

## Arquitectura

La aplicación utiliza Firebase como infraestructura principal para autenticación, almacenamiento de información y servicios backend, junto con React y TypeScript para la interfaz y lógica del cliente.
